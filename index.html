New File

Create an empty text or Markdown file, or a blank Word, Excel or PowerPoint document, in the folder you're looking at. Add your own templates, too. Untitled, Untitled 2… an existing file is never overwritten.

Copy the full path of the selected items, one per line when you select several, ready for Terminal, a script or a message.

Open in Terminal or Editor

Open the current folder, or the folder you selected, in Terminal, iTerm2, Warp, Visual Studio Code or Cursor — whichever you have installed.

Support

Answers to common questions. Requires macOS 27 or later.

The menu doesn't appear.

Make sure Just Right Click is enabled in System Settings → General → Login Items & Extensions. The status banner at the top of the app's settings window shows what's missing and offers a button to fix it. Managed (corporate) Macs may block extensions by policy.

Creating a file fails.

Click Re-authorize… at the bottom of the settings window and choose a folder that contains the destination — Macintosh HD covers every folder on your Mac. Read-only locations and other access restrictions can still prevent writing.

There's no menu in iCloud Drive or a cloud-sync folder.

Some synced locations don't show extension menus. Add Just Right Click to the Finder toolbar (View → Customize Toolbar…), or turn on Enhanced Mode in Settings → Advanced — it needs the menu bar icon, Accessibility and Automation permission — and use Shift-right-click.

Why does the menu stay after I quit the app?

The menu comes from a Finder extension that macOS manages. When you choose an action, the system opens Just Right Click for a moment to do the work, then it quits. To turn the menu off completely, choose Disable Completely… in Settings and switch off Just Right Click in the list — or turn off all three actions in Settings to clear the menu.

Which apps can open folders?

Terminal, iTerm2, Warp, Visual Studio Code and Cursor — the ones installed on your Mac. Choose which appear in the menu in Settings → Open With → Manage….

Does it work on external drives?

Yes. On ExFAT-formatted disks, templates that are packages (bundles) can't be created and the app tells you so; regular files and templates work.

Which languages are supported?

English and Simplified Chinese. The Finder menu follows your Mac's system language; other system languages show English.
