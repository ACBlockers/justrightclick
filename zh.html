新建文件

在当前文件夹里直接新建空白文本、Markdown，或空白的 Word、Excel、PowerPoint 文档，也可以用自己的文件做模板。「未命名」「未命名 2」……绝不覆盖已有文件。

拷贝路径

拷贝所选项目的完整路径；选中多个时每行一个，直接粘贴进终端、脚本或消息。

在终端或编辑器中打开

用终端、iTerm2、Warp、Visual Studio Code 或 Cursor 打开当前文件夹，或你选中的文件夹；只显示你已安装的应用。

贴合访达的使用习惯。

菜单项就在你每天在用的右键菜单里。一次买断，没有订阅，不联网，不做统计。

工具栏按钮

在访达的「自定义工具栏」里加入「轻右键」按钮，一键打开同样的菜单。

外接磁盘

本地文件夹和外接磁盘都能用。新文件总会取一个空闲的名字，不会重名覆盖。

增强模式

可选，默认关闭。部分 iCloud 云盘和网盘同步文件夹不显示扩展菜单，这时按住 Shift 点按右键即可唤出轻右键。需要「辅助功能」与「自动化」权限。

隐私优先

不联网、不做统计、不需要账号。设置和模板只保存在你的 Mac 上。隐私政策

一分钟上手。

第一次打开时，引导会带你完成两个简单步骤。

  1. 启用访达扩展。点按「打开系统设置」，在列表里打开「轻右键」的开关。
  2. 授权一次文件夹访问。点按「授权 Macintosh HD…」并选择 Macintosh HD，之后在任何位置都能新建文件。
  3. 在任意文件夹点按右键。到「下载」里试试：新建文件、拷贝路径、在终端中打开，都在这里。

支持

常见问题解答。需要 macOS 27 或更高版本。

右键菜单不出现？

确认已在「系统设置 → 通用 → 登录项与扩展」中启用轻右键。轻右键设置窗口顶部的状态栏会显示缺少哪一步，并提供修复按钮。公司管控的电脑可能被策略禁用扩展。

新建文件失败？

点按设置窗口底部的「重新授权…」，选择包含目标位置的文件夹；选 Macintosh HD 就能覆盖整台 Mac。只读位置或其他访问限制仍可能阻止写入。

iCloud 云盘或网盘文件夹里没有菜单？

部分同步位置不显示扩展菜单。可以在访达的「显示 → 自定义工具栏…」里加入「轻右键」按钮；也可以在设置的「高级」里开启增强模式（需要菜单栏图标、「辅助功能」和「自动化」权限），再按住 Shift 点按右键。

退出 App 后，右键菜单为什么还在？

右键菜单由系统管理的访达扩展提供。选择某个操作时，系统会短暂打开轻右键完成它，随后自动退出。想彻底停用：在设置里选「彻底停用…」，在列表中关掉「轻右键」；或者关闭设置里全部三个功能，菜单即刻清空。

哪些应用可以打开文件夹？

终端、iTerm2、Warp、Visual Studio Code 和 Cursor 中你已安装的那些。在设置的「打开方式 → 管理…」里选择要显示哪些。

外接磁盘能用吗？

能。在 ExFAT 格式的磁盘上，文件包类型的模板无法新建，App 会给出说明；普通文件和模板都正常。

支持哪些语言？

简体中文和英文。访达右键菜单跟随 Mac 的系统语言；其他系统语言下显示英文。
